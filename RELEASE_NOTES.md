# Marble Rush 1.4.1

- Fixed: in Finger mode the joystick stopped after 1–2 seconds when the finger
  was held down (the browser turned it into a long-press). Holding now works
  for as long as you like.

# Marble Rush 1.4.0

New in 1.4.0:
- 🎮 Control style in the main menu: Buttons (as before), Finger or Both.
  Finger: put your thumb anywhere on the playfield and drag – left/right steers,
  up slows down, down boosts, the further you drag the stronger (never stronger
  than a button). A ring shows where you started. Finger mode hides the buttons.

# Marble Rush 1.3.0

New in 1.3.0:
- 👻 Six ghosts: your best run plus 5 slots of your own. Save any run from the
  game-over screen ("Save as ghost", pick a slot to replace when all are used)
  and race it right away. Pick the ghost to race in the Endless menu; saved
  ghosts can be deleted. Beating a saved ghost on its track updates that slot.
- Fixed: after a run without coins the game-over screen still showed the
  previous run's coins and total

# Marble Rush 1.2.0

New in 1.2.0:
- 👻 Ghost Mode (Endless): race against the ghost of your best run, Trackmania style.
  With Ghost Mode on you drive the exact track of your best run and see your
  ghost plus the gap (+/− m). Beat it and your new run becomes the ghost.
  With Ghost Mode off every run is a new random track, as before.
- PvP is now called Versus

# Marble Rush 1.1.0

New in 1.1.0:
- Fills the whole screen on tall phones (no more black bars)
- New look: a void start screen and modern menus everywhere
- Pause menu (resume, restart, main menu) and a Main Menu button after a run
- Back button now pauses a run and leaves sub-menus instead of closing the app
- Clearer difficulty: Easy, Normal, Hard and the new Insane, with a fine-tune slider
- PvP: smarter rivals that steer around obstacles – fair speed, difficulty is pure skill
- Fixed: picking up Speed in PvP also made every rival faster
- Removed the Optimal Path option

Fixes in 1.0.4:
- Smoother gameplay: adaptive glow quality on slower phones, cheaper background/track rendering
- Music and sound effects pause when the app goes to the background
- 3-2-1 countdown when returning to a run from the background


Fixes in 1.0.3:
- White/black screen on phones with an outdated Android System WebView (now shows an update hint)
- Android back button did not work
- Menu briefly shown zoomed in on start


- Endless run mode: outrun the void, collect coins and pickups (Speed Boost, Magnet, Void Slow, Shield, Ghost) and survive Power Rush corridors
- PvP race mode against up to 10 AI marbles
- Coin shop, achievements and saved best distance
